这是什么页面？

您正在访问 cdn.nlfts.dev 的根域名。该域名专门用于分发公开的静态文件，例如：

  • 图片与媒体资产 (/public/images.png)
  • 公共 JavaScript 与 CSS 脚本文件
  • 开源项目下载及公开文档
使用警示：本CDN仅供组织内部需求使用，严禁未经授权用于任何私利或商业目的。

如何使用？

请直接使用指向您所需文件的完整 URL 路径。正确的文件链接格式示例：

https://cdn.nlfts.dev/public/file-name.ext
